Lab: Tree-based Methods using Heart Data

In this lab, we will explore tree-based methods for classification. We’ll use the Heart dataset, which contains a binary outcome AHD for 303 patients who presented with chest pain. An outcome value of Yes indicates the presence of heart disease based on an angiographic test, while No means no heart disease. There are \(p=13\) predictors including Age, Sex, Chol (a cholesterol measurement), and other heart and lung function measurements.

Bagging

Bagging is a random forest where mtry equals the total number of predictors — every tree in the ensemble considers all predictors at each split, so the only randomness comes from bootstrap resampling the training rows.

Random Forest

Unlike bagging, a genuine random forest restricts each split to a random subset of predictors (mtry = \(\sqrt{p}\) by convention for classification), which decorrelates the trees in the ensemble.

Live-coding demo: fill in mtry with sqrt(ncol(heart) - 1) (the random forest default) first, then re-run with ncol(heart) - 1 (equivalent to bagging) — compare accuracy and the importance rankings between the two.
