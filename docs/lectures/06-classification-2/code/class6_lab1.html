Introduction

In this lab, we will:

  1. Load and explore the iris dataset.
  2. Visualize the data to understand the relationships between variables.
  3. Split the data into training and testing sets.
  4. Train three different types of SVM models: linear, polynomial, and radial basis function (RBF).
  5. Evaluate and compare the performance of these models on the test data.

Every code cell below runs live in your browser via webR — no local R install needed. Edit any cell and re-run it. Packages load once when the page opens; give it a few seconds on first load. The polynomial SVM tuning cell fits over 100 models via cross-validation and is the slowest cell in this lab — expect a real wait in-browser.

Examine the Data

The iris dataset is a classic dataset in machine learning and is built into R. It contains measurements for 150 iris flowers from three different species: setosa, versicolor, and virginica.

Interpretation of the Data: The dataset has 150 observations and 5 variables. Sepal.Length, Sepal.Width, Petal.Length, and Petal.Width are all numeric, and Species is a categorical variable with 3 levels. There are 50 samples for each of the three species.

Visualization

Visualizing the data is a crucial step to understand the separability of the classes. We create two scatter plots: one for sepal dimensions and one for petal dimensions. We color the points by Species to see how distinct the groups are.

Plot Interpretation: The species are much more clearly separated when we plot them by their petal dimensions. The sepal dimensions show significant overlap, especially between the versicolor and virginica species. For this lab, we will intentionally use the more challenging sepal features to see how well SVM can perform.

Training and Testing Splits

To evaluate our model’s performance on unseen data, we must split our dataset into a training set (used to build the model) and a testing set (used to evaluate it). We’ll use an 80/20 split.

We use the createDataPartition function from the caret package to create a stratified split, which ensures that the proportion of each species is the same in both the training and testing sets.

Note: For this analysis, we are only using Sepal.Length and Sepal.Width as our predictors.

Fitting SVMs

Interpretation: Compare accuracy and per-class sensitivity across the three confusion matrices above. All three kernels tend to identify setosa perfectly (it’s linearly separable even on the harder sepal features), but differ on how well they separate versicolor from virginica, which overlap more. If the RBF kernel comes out ahead, that suggests the true decision boundary between those two species is non-linear.

Conclusion

This exercise demonstrates the importance of testing different kernels and tuning hyperparameters to find the best model for a given dataset — the “best” kernel isn’t knowable in advance, only by comparing held-out performance.
